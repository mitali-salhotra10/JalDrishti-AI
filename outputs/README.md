# Outputs Directory (`outputs/`)

This directory stores rendered figures, cartographic maps, and tabular evaluation summaries produced by the JalDrishti-AI pipelines.

## Subdirectories

- `figures/`: High-resolution analytical figures, comparative panels, and distribution plots.
  - `watershed_village_indicators_panel.png`: 3-panel comparative cartography comparing (1) Preliminary Screening Score, (2) 25-Year Baseline Rainfall, and (3) Agricultural Cropland Intensity across all 518 catchments.
- `maps/`: Vector GIS map exports.
  - `jaldrishti_preliminary_watershed_screening.svg`: High-resolution vector publication map showing preliminary screening categories across Maharashtra in UTM Zone 43N.
- `tables/`: Tabular export summaries and diagnostic statistics.
